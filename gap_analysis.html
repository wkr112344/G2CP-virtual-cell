3. 我们手里的真实状态（诚实交代）

  • 做对的：两阶段（遗传预训练→化学微调）骨架跑通了；用的是真实公开数据（Norman / sciPlex3 / LINCS / DepMap），不是合成标签糊弄；分子图编码器、对比预训练都按论文思路落地了；还多做了一个论文没有的"药→靶点→通路→表型"交互解释工具（chain.html）。
  • 没测的：上面那些 PCC、SMD、EF 硬指标，我们一个都没算。我们只有 stageB 的训练损失从 1.15 降到 0.68——这只是"模型在拟合训练集"，不是"比基线准多少"。
  • 代际差的：蛋白编码器。论文的核心是 ESM 级"增强蛋白编码器"，把序列语义塞进统一空间；我们因为 4GB 显存装不下 ESM，退成了轻量 CNN。这是和我们差距里最要命的一块（前面查过，ESM2-8M 你的卡能装，是补这个洞的钥匙）。

4. 要追上"论文水平"，依次要补什么

  1. 先上 ESM2-8M 蛋白编码器（你 4GB 能装）—— 这是论文的"增强蛋白编码器"最低成本近似，直接补最大的洞。
  2. 把规模提上来：基因从 237 → 上千（DepMap 全量），化合物从 51 → sciPlex3 全部 188+ / 或接 LINCS 上万化合物，细胞系从 1 → 多系。本机 4GB 跑不了全量，但可用采样/梯度累积分批训。
  3. 把定量基准补上：实现 PCC vs chemCPA、MoA-SMD、CPI-EF 这三个指标，让"我们比随机/比基线好多少"有数字支撑——不然永远只是"能跑"，不是"能发"。
  4. 补增强损失 / Mantel：论文靠它们做上下文特异性，属于锦上添花，可放最后。
现实提醒：论文是 5 细胞系 × 7860 化合物 × 4994 基因 + ESM 大模型级的算力。我们 4GB 笔记本的定位是"原理验证 + 教学演示 + 小规模真实预测"，不是去复刻它的规模。把 1、3 做了，就能从"课堂原型"升到"小规模但指标可对标"的水平。
